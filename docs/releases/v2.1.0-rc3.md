# CYBREX Presence v2.1.0-rc3

> Release Candidate — intended for real-device validation before the first stable v2.1.0 release.

## Highlights

- Desktop control center for Windows and Linux.
- Discord Rich Presence for games, browsers, media, coding, terminals, and supported desktop applications.
- Privacy-safe Browser Companion integration for richer browser activity.
- Social web presence for WhatsApp Web, Facebook, Messenger, Instagram, LinkedIn, Threads, TikTok, Telegram Web, Snapchat Web, Discord Web, Pinterest, Bluesky, X, and Reddit.
- Local game discovery for Steam, Epic Games, and Heroic/Legendary.
- Enhanced integrations for Counter-Strike 2, FiveM, Minecraft, and League of Legends where supported.
- Gamer Mode and configurable activity priorities.
- Clickable Rich Presence links for recognized browser/media services, with duplicate-link prevention.
- Strict privacy mode continues to suppress browser/media links and buttons.

## Verification

Every downloadable artifact is covered by `SHA256SUMS.txt`. Verify a file before installation when possible.

Windows PowerShell:

```powershell
Get-FileHash .\CYBREX-Presence-Setup-2.1.0-rc3-windows-x86_64.exe -Algorithm SHA256
```

Linux:

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```

Windows Authenticode signing is applied only when the repository owner has configured the signing certificate secrets. An unsigned RC can trigger Windows SmartScreen even when the checksum is valid.

## Important RC limitations

- This is not the stable `v2.1.0` release.
- Real Discord Desktop, Windows 10/11, KDE Plasma Wayland, GNOME Wayland, Sway, and live game integrations still require real-device validation beyond hosted CI.
- Discord legacy RPC may continue to show the registered CYBREX application name at the top of the activity card. Dynamic top-level application names require the optional Discord Social SDK transport and separate real-device validation.
- Browser/social presence intentionally avoids publishing private conversation names, account identifiers, deep social links, or private/incognito metadata.

## Validation expected before v2.1.0 stable

- Install, launch, update, restart, and uninstall on Windows 10/11.
- Validate Discord reconnect after Discord is restarted.
- Validate clickable buttons on YouTube/Twitch/Spotify and browser service activities.
- Validate Steam/Epic/Heroic game discovery on real installations.
- Validate KDE/GNOME/Sway foreground behavior on real desktops.
- Run a longer Windows/Linux soak test and review CPU/RAM/thread/file-descriptor behavior.
- Confirm current screenshots and release documentation match the packaged UI.

Report reproducible issues through GitHub Issues and include the operating system, desktop/session type, CYBREX version, and relevant redacted diagnostics.
