# CYBREX Presence v2.1.0-rc5

This is a public **Release Candidate**, not the final stable release.

## Highlights

- Desktop UI v4 with a cleaner sidebar, improved spacing, cards, status hierarchy and local UI icons.
- Arabic rendering fixes with shaping/BiDi support and mixed Arabic/Latin handling.
- Linux RAM/resource hardening: fixed HTTP worker pools, bounded GUI probing, safer Discord RPC cleanup, removal of the pydbus polling fallback, and memory/resource diagnostics.
- Invalid optional Rich Presence URLs now fail soft instead of preventing the service from starting.
- Built-in update UI with Stable/Preview channels and verified download/install flow.
- Curated compatibility targets for 346 popular games, while launcher metadata remains authoritative where available.
- Improved application/game artwork resolution for browsers, editors, terminals, communication apps, launchers and popular desktop applications.
- Optional Discord Social SDK transport for dynamic activity identity has been implemented with a private stdin/stdout bridge and legacy RPC fallback.

## Discord activity-name note

The official Discord Social SDK runtime/helper is **not bundled in this RC**. Without that helper, CYBREX falls back to legacy Discord RPC, where Discord may still show the registered application name (`CYBREXTech`) as the top-level `Playing` identity. The dynamic program/game name path is implemented but must be validated with the official Social SDK before the stable release.

## Reliability validation

The RC5 release workflow rebuilds the artifacts from source and requires:

- full Python regression suite;
- dependency audit and high-severity Bandit scan;
- Linux packaged-binary smoke test;
- Linux user-level install, launch and uninstall test;
- Windows packaged-binary smoke test;
- Windows silent install, launch and uninstall test;
- Browser Companion syntax/package validation;
- SHA-256 verification before publication.

## Still required before v2.1.0 stable

- multi-hour real-device RAM soak on the latest Linux build;
- real Discord Desktop validation of the Social SDK helper/dynamic application name;
- Windows Authenticode signing integration for the stable Windows release;
- final real-device Windows/Linux desktop checks and release screenshots.

Please report any continuously growing RSS, desktop hangs, startup failures, incorrect Arabic text, or incorrect detected application/game identity before stable promotion.
